# anonimizador_columnas
Anonimizador y selector de columnas a partir de un archivo excel

Vas a crear código para resolver uno de esos problemas cotidianos que te sucede con grandes bases de datos en excel. Pero necesitas anonimizar columnas, para no subir ningún dato sensible a un modelo LLM.
Esta es la solución. Con esta pequeña aplicación en html en local puedes anonimizar fácilmente las columnas que te interesen, seleccionar con las que te quedas, y descartas las que no te hacen falta. 
Objetivo: Trabajar seguro y no subirle en ningún caso información sensible a un modelo de LLM.
Nota: además de anonimizar, utiliza la minima cantidad posible de datos y si es posible, modificalos un poquito para minimizar al máximo el riesgo de reidentificación.
Que lo disfruten!
